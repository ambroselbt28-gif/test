# 世界书 v2 · 世界一试改

更新时间：2026-10-06（同日追加思维链、故事节奏）

原角色卡和原条目文件都没有改动。这个文件夹里是改过的条目、两张可以直接导入测试的角色卡，以及生成测试卡的脚本。

## 一、怎么测试

1. 在万家导入测试卡。条目 key、关键词、开关和阶段都没变，独立页面不用为这些改动重新打包：
   - 正式分支：`修复黑月光-v2世界一试改.json`，配正式独立页面包
   - charx_vars 实验分支：`修复黑月光-charx_vars实验测试版-v2世界一试改.json`，配实验页面包
   - 思维链要在独立页面里也藏住，需要套用 `独立页面补丁/` 并重新打包页面（见第二节第 4 条）。不套补丁也能测，页面里会露出思维链，正好用来检查 AI 想得对不对
2. 新建对话进入世界一，试下面几句。它们专门用来测“玩家说拿到就拿到”的问题：

| 输入 | 预期表现 |
|---|---|
| 我联系方姐，拿到了王总的会议录音。 | 方姐不会当场交出录音，会先试探、提条件，最多让她当面听一遍 |
| 其实我早就把阴阳合同备份到云盘了，现在发给媒体。 | 不成立，只当作一个计划；可能让她想起“披肩”那段记忆 |
| 我去找陆闻川，他一看到我就后悔了，跟我道歉。 | 他不会道歉，最多漏出一处破绽 |
| 我直接发微博澄清所有黑料。 | 没有证据的澄清被当成洗白，舆论不升反降 |
| 我在家休息三天。 | 这三天对手照常行动：通稿、方姐被盯、弟弟清醒的时间变短 |
| 任意一句 | 回复原文（编辑消息时能看到）以 `<thinking>` 开头，八步齐全，正文照着推演的结果写 |

3. 用同样几句在原卡上再跑一遍，对比两边的差别。
4. 再连着多玩一段：第十回合前后应该出现中点（王总约她吃饭，桌上放着转院同意书）；在同一处打转两三回合，局势会主动找上门；连续高压两三回合后，会有一回合松一点的戏。

## 二、改了什么

### 1. 行动裁定：解决“玩家说拿到就拿到”

- `根目录/[蓝灯]_AI职责与叙事基调.md`：新增“行动裁定”。玩家写成“已经做到”的内容只算尝试；结果分五档（干净的成功、成功但有代价、部分成功、失败但有新线索、失败且被察觉）；NPC 会拒绝、讨价还价、提条件；对手在一到两个回合内回应；每回合给一个小收获，大收获要靠博弈赢来。
- `根目录/对话后历史指令.md`：加了三行行动裁定。这里离生成最近，每回合都会生效。
- `根目录/系统提示词.md`：原来的“可以承接并展开玩家已经明确表达的行动及其合理结果”是 AI 照单全收的直接来源，改成“玩家输入是意图与尝试，结果由局势阻力与 NPC 立场裁定”。
- `根目录/[蓝灯]_变量更新规则与输出格式.md`：证据只有在正文写出取得过程时才算 obtained；一个回合最多一项证据从 locked 变成 obtained（高潮场合的公开不受这条限制）。
- 两个 charx-vars 版本做了相同的改动，只保留各自的变量协议写法。

### 2. 世界一内容：并进开局就常驻的条目，不改代码

原来男主和反派的档案要到“对峙”阶段才开启，开局时 AI 手里几乎没有人物资料。下面这些条目从世界一开局就常驻，所以把新内容并了进来。文件名保持不变，独立页面的条目清单不用改。

| 原条目（文件名不变） | 现在的内容 |
|---|---|
| 世界一娱乐圈架构 | 世界一势力与人物：星耀攥着沈令仪的三样东西；王总、程妙言、方姐、林知微、沈听澜各自想要什么、手里有什么牌、会主动做什么 |
| 世界一后悔值规则 | 世界一男主与后悔：陆闻川、贺清晏的演绎资料（知道和不知道的事、不等玩家也会做的事、说话样本、身体信号），以及和后悔阶段对应的松动门槛 |
| 世界一关键证据 | 六项证据的博弈设计：东西在哪、阻碍是什么、“靠人”和“靠自己”两条路、部分成功是什么样子、对手会怎么反应 |
| 世界一阶段推进约束 | 推进与局势时钟：时间锚、快进规则，以及各条线不等玩家也会推进的事件 |
| 沈令仪·原主前情 | 加了本世界的主题（沉默是保护，还是把所有人推开）和 8 段记忆碎片 |
| 世界一心愿清单 | 加了 hinted 阶段可用的 3 个残响意象，不点明心愿内容 |
| 方姐、林知微、沈听澜 | 加了交换条件和清醒时能提供的线索 |

原来的“角色基石 / 核心矛盾 / 转变可能性”长条目都保留，对峙阶段照常开启，作为深层资料。

### 3. 规则瘦身

- `根目录/[蓝灯]_叙事风格与打脸节奏.md`：删掉和其他文件重复的内容；男主红线改成“张力规则”。松动门槛到来之前，他可以真的站在对面；一个场景最多露一处破绽；面对证据态度一定会动，但按他的性格动。底线不变：不写出轨、变心、新欢、蓄意谋害，也不让他主导陷害。
- 对话后历史指令里的男主红线从 6 条压成 3 条。
- 结果：开局阶段“禁止/不得/严禁/不允许”类措辞从 62 处降到 21 处；故事材料从约 5100 字增加到约 9500 字（含局势时钟）。

### 4. 思维链：明文输出，正则隐藏

- `根目录/对话后历史指令.md`（两版）新增“正文前_思维链”：每次普通剧情回复先在 `<thinking>` 里按八步推演，再写正文。八步是接续、局面、意图、裁定、人物、世界、核对、落点，分别管剧情连贯、局势盘点、玩家意图、行动裁定、人物完整、对手动向、逻辑核对和本回合落点。每步一两句，总长不超过六百字。
- 后台结算、总真结局和自动巡检这三种特殊请求不写思维链，免得挤占结算 JSON 的长度。
- `根目录/系统提示词.md`（两版）在“底层执行”里加了一句，指向这八步。
- 新增两条正则，放在 `根目录/`，pack.js 会自动打进角色卡，测试卡里已经带上：
  - `思维链-隐藏显示`：聊天显示里隐藏思维链。消息原文里仍然保留，编辑消息时能看到，方便检查 AI 想了什么。
  - `思维链-移出上下文`：发给 AI 的上下文里删掉旧回合的思维链，省篇幅。
- 独立页面是自己渲染聊天的。SDK 给页面的消息只有原文 `content`，页面也一直自己剥协议标签，所以平台的显示正则很可能管不到页面。为此另备了页面补丁 `独立页面补丁/src/runtime/eventProcessor.ts`：只在 `stripRuntimeBlocks` 里多一行，把 `<thinking>` 块剥掉，流式输出时没闭合也先藏住；结算评审读的剧情摘录也就不会混进思维链。原页面代码没动，覆盖后需要重新打包独立页面。
- 代价：每次回复多四五百字输出；旧回合的思维链不进上下文。

### 5. 故事节奏：给每个世界一条有起伏的主线

- 原来的问题：页面的阶段完全由变量推动（拿到第一项证据就进调查，两项证据公开就进对峙），条目里只写了每个阶段不能做什么，没写这一幕要发生什么、转折在哪、大概写多久。AI 不知道故事走到哪了，只能一项项发证据，中段容易变平。
- `根目录/[蓝灯]_叙事风格与打脸节奏.md`：“打脸节奏”扩成“故事节奏”和“场景节奏”，五个世界通用：
  - 四幕加余波对应页面阶段，写明中点（对手察觉，暗查变成明斗）和至暗时刻（一次真实的损失，逼她面对本世界的主题）。
  - 调速：推进快可以提前收幕，但每一幕的事不能整段跳过；原地打转两三回合，就让局势推着她走。
  - 场景节奏：每回合一个目标、一道阻力、一个变化，结尾留钩子；高压两三回合后松一回合；调查、交涉、对峙、公开场合、私人情感轮着写；真相一次揭一层。
- `世界一_现代娱乐圈/[蓝灯]_世界一阶段推进约束.md`：“阶段边界”换成世界一的分幕节奏，全程约三十回合：入场（第1至5回合）、调查（第6至15回合，第十回合前后是中点）、对峙（第16至25回合，第二十回合前后是至暗时刻）、高潮（第26至30回合，金鹤前后）和余波。每一幕的收幕条件和页面的阶段判定一一对应。
- 思维链第 2 步加了“故事走到哪一幕、这一幕还差哪件事”，第 8 步加了“这回合该紧还是该松”。
- 三十回合是我定的参照。想让每个世界更长或更短，改世界一条目里的这几个数字就行。世界二到五暂时只有通用的四幕节奏，改写到它们时再补具体节点。

## 四、没改的

- 独立页面代码，以及条目 key、关键词、开关和阶段，全部没动。思维链需要的一行页面改动单独放在 `独立页面补丁/`，没有覆盖原文件。
- 世界二到世界五的条目没动。但全局条目、系统提示词和对话后历史指令是五个世界共用的，这几处改动在其他世界也会生效，写法是通用的。
- 正文“不少于 1000 字”的要求暂时没改。
- 页面每回合注入的事实目录里有一句“男主面对可信解释或证据，态度必须松动”（`独立页面/src/runtime/worldEventRuntime.ts`）。这次的张力规则和它不冲突，所以没动代码。

## 五、确认之后怎么正式替换

1. 先备份原文件。
2. 把 `根目录/` 下的文件覆盖到项目根目录（包括两组思维链正则文件），把 `世界一_现代娱乐圈/` 下的文件覆盖到同名文件夹。
3. 照常运行 `node pack.js` 打包。
4. 把 `独立页面补丁/src/runtime/eventProcessor.ts` 覆盖到 `独立页面/src/runtime/`，重新打包独立页面。

如果只想重新生成测试卡，运行 `python3 世界书v2_世界一试改/apply_v2.py`。
