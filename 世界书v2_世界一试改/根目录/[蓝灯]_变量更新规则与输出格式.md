        - 只有本轮正文写出了取得过程、证据实际到手才算 obtained；玩家输入里声称已经拿到、正文却没有写出取得过程的，不改变状态

变量输出格式:
  rule:
    - 每次回复末尾输出一次 UpdateVariable
    - UpdateVariable 包含英文 Analysis 和 JSONPatch
    - Analysis 使用英文，80~180 词；先列出本轮实际变化的正式路径，再分析这些变化的完成事实
    - JSONPatch 是合法 JSON 数组，只使用 delta、replace、remove
    - delta 仅用于 metrics 和 regrets，value 为带正负号整数
    - replace 用于证据、心愿、flags、阶段和最终值
    - evidence、metrics、regrets、mainWishes、sideWishes、flags 等字段路径统一使用状态结构里的正式 ID
    - evidence、心愿、flags、metrics 和 regrets 的正式字段以本轮注入的完整变量快照为准，路径必须原样复制
    - 先逐项检查本轮正文是否完成了证据取得/公开、指标事实、后悔值触发、主线心愿、支线心愿、flags 或隐藏心愿阶段；每个已完成且满足对应条目定义的事实都必须有一条对应 JSONPatch
    - 对每个本轮已完成的目标，回看当前世界的心愿清单，使用对应正式 wishId 在 mainWishes 或 sideWishes 路径中提交 false → true
    - 例如“救回被控弟弟”对应 /worldStates/w1/mainWishes/brotherRescued，value 只填写 true
    - Analysis 中写出“已完成/已救回/已获释/已公开/已达成”等结果时，必须同时提交对应变量 patch；不能只写分析而不更新变量
    - 每条 JSONPatch 都必须逐字复制 Analysis 中已列出的正式路径，并能在本轮正文找到已完成事实依据；没有对应完成事实时保持不变
    - phase 是页面派生字段，JSONPatch 不得包含 /worldStates/${currentWorld}/phase；不要自行提交阶段变化
    - 只提交当前世界本轮变化；没有变化时输出 []
    - UpdateVariable 后输出 3 项 moonlight_choices，闭合后结束
  format: |-
    <UpdateVariable>
    <Analysis>$(IN ENGLISH, 80-180 words)
    - Identify completed facts in the current reply.
    - Check evidence, regret, metric, wish, flag, and hidden-wish changes.
    - For every completed objective, map it to the current world's formal wishId and include the matching mainWishes or sideWishes patch.
    - Use only facts completed in this reply; do not infer plans or future results.
    </Analysis>
    <JSONPatch>
    [
      { "op": "replace", "path": "/worldStates/${currentWorld}/evidence/${正式evidenceId}", "value": "obtained|public" },
      { "op": "delta", "path": "/worldStates/${currentWorld}/regrets/${targetId}", "value": +${5-20} },
      { "op": "delta", "path": "/worldStates/${currentWorld}/metrics/${metricId}", "value": +${-30-30} },
      { "op": "replace", "path": "/worldStates/${currentWorld}/mainWishes/${formalWishId}", "value": true },
      { "op": "replace", "path": "/worldStates/${currentWorld}/sideWishes/${formalWishId}", "value": true },
      { "op": "replace", "path": "/worldStates/${currentWorld}/flags/${flagId}", "value": true },
      { "op": "replace", "path": "/worldStates/${currentWorld}/hiddenWishStage", "value": "hinted|revealed|completed" }
    ]
    </JSONPatch>
    </UpdateVariable>
